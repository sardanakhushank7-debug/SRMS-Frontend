# Savor — Smart Restaurant Management System

## Project Overview

Savor is a React-based restaurant management frontend designed to provide customers with a simple and convenient restaurant ordering experience. Users can explore food items, search the menu, filter available options, manage their shopping cart, place a demo order, make reservations, and interact with a chatbot.

The project focuses on building a clean, user-friendly interface using React and modern frontend development practices.

## Features

### 1. Interactive Menu
- Displays food items with images, names, descriptions, and prices.
- Allows users to search for food items.
- Provides category filters and vegetarian filtering.

### 2. Shopping Cart
- Add food items to the cart.
- Increase or decrease item quantities.
- Remove items by reducing their quantity to zero.
- Calculate the subtotal, applicable tax, delivery fee, and final total.

### 3. Checkout and Order Confirmation
- Collects customer information during checkout.
- Validates required fields.
- Displays an order confirmation after a successful demo order.

### 4. Reservations and Private Events
- Supports table reservations and private event requests.
- Collects reservation details through a form.
- Validates form inputs and displays submitted reservation information.

### 5. Chatbot
- Allows users to send messages through a chat interface.
- Provides responses to help demonstrate basic customer interaction.

### 6. Responsive User Interface
- Uses a restaurant-themed design with food imagery.
- Organizes content into clear sections for easier navigation.

## Technologies Used

- **React** — building the user interface and reusable components.
- **JavaScript** — application logic and interactive functionality.
- **CSS** — styling, layout, and visual design.
- **Vite** — development server and production build tooling.
- **npm** — package management and project scripts.


## Project Scope and Limitations

This project focuses on the frontend and demonstrates the main user interactions of a restaurant ordering system.

Order confirmations, reservations, and chatbot responses are implemented as frontend demonstration features. Unless additional backend or persistent storage functionality has been implemented, data should not be considered permanently stored, and the chatbot should not be described as a real AI service.

The application does not represent a live payment processing system.

## Conclusion

Savor demonstrates how React, JavaScript, and CSS can be used to create an interactive restaurant frontend. The project brings together menu browsing, cart management, checkout, reservations, and customer interaction in one interface.

The project also provides practical experience with component-based UI development, state management, form validation, and testing interactive features.
